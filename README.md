# Stock Manager

Application web de gestion de stock créée avec Django.

## Fonctionnalités

* Gestion des produits
* Gestion des catégories
* Ajouter, modifier et supprimer des produits
* Ajouter, modifier et supprimer des catégories

## Technologies

* Python
* Django
* HTML
* Bootstrap
* SQLite
